# Microjournal

`index.html` をブラウザで開くだけで使えます。Markdownを入力して「投稿」を押すと、端末のローカル日時を使った `YYYY-MM-DD_HH-mm-ss_一行目.md` をダウンロードします。一行目の先頭10文字までを使い、ファイル名に使えない文字は置き換えます。一行目が空の場合はタイムスタンプのみになります。Obsidianの保管庫に保存または移動して利用できます。

本文の前に、タイムゾーン付き `created` と `tags: [microjournal]` のYAML front matterが付きます。投稿後、入力欄は空になります。アプリは投稿を送信・永続保存しません。ページを閉じると未投稿の下書きは失われます。

アプリは確認画面を表示しませんが、ブラウザの設定によっては保存先の確認画面が出ます。同じ秒に複数投稿した場合は同じファイル名になるため、ブラウザが名前を変更することがあります。

GitHub Pagesでは `index.html` を公開対象のディレクトリに配置してください。ビルドや外部ライブラリは不要です。
